Namespaces

What each namespace has today, the proposed quota, and what stands in the way. Click a row for the details.

Requests are effective pod requests (init / sidecar containers and overhead included), as the quota counts them. Peak = the highest Σ requests over the window (Prometheus); without Prometheus, peak = now. HPA max = requests if every HPA scaled to maxReplicas (the average of its pods' requests × the replicas to add). "Quota now" is the tightest unscoped ResourceQuota in the namespace with its used value; Rancher = created by a Rancher Project quota. Status: ready — a quota can go on; needs defaults — containers without requests or a memory limit would be refused, the LimitRange has to come first; has quota — compare with the proposal; blocked — the current quota is below today's requests. Nothing here is applied: the exports go through the allocation files and a pull request.
