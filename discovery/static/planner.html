Clusters

Capacity and node sizes from Rancher; planned = Σ of the quotas below. Values are CPU / GiB.
How much each cluster can give to projects (CPU and memory separately):
  1. Allocatable of the schedulable nodes,
  2. minus the largest node(s) — N+1: if the environment tolerates N node failures (prod: 1), all project quota must still fit after the N largest nodes are gone,
  3. minus the platform reserve — what platform components (cattle-*, kube-system, monitoring, ingress …) request. They are in no project quota but take capacity first. It is measured for the cluster this planner runs on; for other clusters enter the System requests shown in that cluster's resource dashboard, or use its total requests now as a safe upper bound,
  4. and at most the environment's max % of allocatable minus the platform reserve (room for rollouts).
The lower of the two results is the limit for projects; the table shows which rule sets it.
