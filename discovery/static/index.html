Requests are effective pod requests (incl. init/sidecar containers and overhead), as counted by the scheduler and ResourceQuota. "Used" is P95 over the window when Prometheus is available, otherwise the current metrics-server snapshot. Efficiency = used / requested. Quota = the tightest ResourceQuota of the namespace (requests.cpu / requests.memory, or cpu / memory); per project the sum over its namespaces that have one, compared with the requests of those namespaces. Quotas with scopes only count some pods and are not included.
